# Support

Presenter Copilot is currently an early-stage, pre-1.0 project.

## Where to ask for help

- Use GitHub issues for reproducible bugs and concrete feature requests.
- Use project discussions, when enabled, for broader product or architecture questions.
- For security-sensitive matters, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.

## Before opening an issue

Please include:

- operating system and version;
- application version or commit SHA;
- relevant hardware, especially GPU/NPU information for local inference issues;
- model/backend configuration;
- clear reproduction steps;
- expected vs. actual behavior;
- sanitized logs when useful.

Do not upload confidential presentations, recordings, transcripts, credentials, access tokens, or private customer data.

## Current support expectations

There is no guaranteed response time or commercial support commitment for the open-source project. Managed or enterprise support may be defined separately in the future.
